# Foolscap

Foolscap is a Mac app for writing books. This repository holds its
releases and the feed that tells Foolscap when an update is ready
(`appcast.xml`, served at https://gocodedotca.github.io/foolscap/appcast.xml).

Download the latest version from
[Releases](https://github.com/gocodedotca/foolscap/releases/latest).
